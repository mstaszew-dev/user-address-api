UserAddress API

A Spring Boot 3 REST API with JWT authentication, in-memory database simulation, and CRUD operations for Users and Addresses. Built test-first with JUnit 5, MockMvc, and a Thymeleaf dashboard UI.

Architecture

  • - 3-layer: Controller → Service → Repository
  • - Map-based storage: ConcurrentHashMap<String, Map<String, Object>>
  • - JWT auth via jjwt with BCrypt password hashing
  • - RBAC: ADMIN role gate on /api/admin/**
